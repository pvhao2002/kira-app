# Multi-Version Concurrency Control (MVCC) in PostgreSQL

Postgres avoids read-write blocking through snapshot isolation with tuples maintaining:

- xmin: inserting Transaction ID

- xmax: deleting/updating Transaction ID

When vacuum freezes xmin, the freeze age counter wraps safely.
