  1. Replace document with embeds, then replace everything after the last / with /content.
    Example:
    https://www.scribd.com/document/861746837/ishq-e-aatish → https://www.scribd.com/embeds/861746837/content
  2. Open the modified link and scroll to the very bottom to make sure all pages are fully loaded.
  3. Open Developer Tools by pressing F12 or Ctrl + Shift + I.
  4. Press Ctrl + F and clear the class values for the following CSS classes:
    • document_scroller
    • toolbar_drop
    • mobile_overlay
  5. Press Ctrl + P (Windows) or Command + P (Mac) to save the document as a PDF file.
