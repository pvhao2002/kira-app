# Kira 3D UI Guidelines

## Scope

This is a Next.js 16 / React 19 / TypeScript application using the App Router and Tailwind CSS 4. The existing `AGENTS.md` is generated by Next.js; preserve it.

## Change Rules

- Next.js 16 behavior may differ from older conventions. Before changing framework APIs, read the relevant local guide under `node_modules/next/dist/docs/` and follow its deprecation guidance.
- Keep routes, layouts, loading/error boundaries, metadata, and server/client component boundaries in `app`. Add `'use client'` only for browser APIs, state, or event handlers.
- Prefer Server Components and server-side data access by default. Do not pass secrets or unnecessarily large objects into client bundles.
- Keep 3D/render loops isolated from ordinary page layout. Dispose geometries, materials, textures, listeners, animation frames, and observers during teardown.
- Respect reduced-motion preferences, keyboard navigation, readable fallbacks, responsive sizing, and low-powered devices. Avoid animation that blocks interaction or layout stability.
- Follow the existing ESLint and TypeScript configuration; do not hand-edit generated `.next` output.

## Verification

Do not run build, lint, tests, or a dev server unless explicitly requested. When visual QA is requested, verify the rendered route and check for console errors, resize behavior, and cleanup after navigation.
